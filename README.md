# Мультитул

Набор онлайн-инструментов с общей навигацией и оформлением.

- `/` — маркетинговый калькулятор: ROAS, ROMI, стоимость привлечения клиента и лида, конверсия, средний чек и выручка для покрытия рекламных расходов.
- `/utm-builder/` — генератор ссылок с `utm_source`, `utm_medium` и `utm_campaign`. Сохраняет остальные параметры и якорь ссылки, заменяет существующие одноимённые метки и кодирует специальные символы.

Сайт: <https://nezagorami56.github.io/multitool/>.

Статический сайт на HTML, CSS и JavaScript. Введённые значения обрабатываются в браузере. Сборка и серверная база данных не требуются.

## Локальный запуск

Из каталога проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем откройте <http://127.0.0.1:4173>.

## Публикация

GitHub Pages публикует корень ветки `main`. Обновления сайта отправляются в эту ветку и публикуются автоматически. Файл `.nojekyll` отключает обработку сайта через Jekyll.

## Допущения расчёта

Маржинальность вводится до рекламных расходов. Результат «Прибыль» учитывает эту маржинальность и рекламный бюджет, но не отдельные постоянные расходы бизнеса. Показатель CAC здесь использует только рекламные расходы, а не полную стоимость маркетинга и продаж. Для сравнения лидов и клиентов нужно использовать согласованный период и воронку.
